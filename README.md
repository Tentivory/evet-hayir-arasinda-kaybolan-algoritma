# Evet-Hayır Arasında Kaybolan Algoritma

## Resmi Kararsızlık Makinesi v1.0

**DİKKAT: Bu proje, insanlık tarihinin en ciddi bilimsel başarılarından biridir.**

Bu algoritma, "Evet mi, Hayır mı?" sorusunun çözümüne dair yıllarca süren derin araştırmaların sonucunda ortaya çıkmıştır. Nobel ödülü adayıdır (adaylığını kendisi vermiştir).

### Ne Yapar?

- Herhangi bir soruya kararsız cevaplar verir.
- Bazen düşünür, bazen düşünmez.
- %100 doğruluk oranına sahiptir (çünkü doğru cevap yoktur).
- Çalışır. Gerçekten çalışır. Deneyin.

### Nasıl Kullanılır?

```bash
python kararsiz_makine.py
```

Sonra bir soru sorun. Mesela "Bu proje mantıklı mı?" diye. Cevabını tahmin edebilirsiniz: Hayır. Veya evet. Veya ikisi de.

### Teknik Detaylar

Bu algoritma, kuantum kararsızlık prensiplerine dayanır. Ya da dayanmaz. Bilmiyoruz. Kod içinde gizli bir mesaj vardır ama bulmanız gerekmez.

### Uyarı

Bu programı kullanmak, hayatınızdaki tüm kararları sorgulamanıza neden olabilir. Sorumluluk kabul edilmez.
